## Hướng dẫn in 3D (3D Printing)
> **Ghi chú:** Chỉ cần xuất và in toàn bộ các file `.STL` nằm trong thư mục `cad/stl_print/` là bạn sẽ hoàn thành toàn bộ phần thân vỏ cơ khí cho robot.

## Cấu trúc thư mục
- `cad/stl_print/`: Chứa toàn bộ các file `.STL` phục vụ in 3D.
- `drawings/`: Bản vẽ lắp tổng thể dạng `.PDF`.
